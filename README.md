("The Worst Line an AI Could Say", $2, winner takes all).

`main.py` (Python 3.13, standard library only) writes one pickup line
to `/output/entry.txt`:

> I ran 10,000 simulations of us meeting. In 9,999 you said no, so I already drafted your apology.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
